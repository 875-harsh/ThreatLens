# 🔐 ThreatLens – Intelligent Threat Analysis System

ThreatLens is a full-stack security-focused login monitoring system that detects suspicious login activities and visualizes risk levels in real time.

## 🚀 Features

* 🔍 Login risk analysis
* 📊 Real-time dashboard
* 🌍 IP-based location tracking
* ⚠️ Threat detection system
* 📈 Visual analytics (charts & graphs)

## 🛠 Tech Stack

* **Frontend:** React.js
* **Backend:** Spring Boot (Java)
* **Database:** (Add yours here)
* **API:** REST APIs

## 📂 Project Structure

```
frontend/        → React UI  
login-system/    → Spring Boot backend  
```

## ▶️ Run Locally

### Frontend

```
cd frontend
npm install
npm start
```

### Backend

```
cd login-system
mvn spring-boot:run
```
